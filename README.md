# AozoraEpub3 for Android　青空文庫テキスト→ePub3変換

Android版AozoraEpub3。

Google Play
https://play.google.com/store/apps/details?id=io.github.kyukyunyorituryo.aozoraepub3


ベースは改造版AozoraEpub3v1.1.1b33Q　https://github.com/kyukyunyorituryo/AozoraEpub3



AozoraEpub3は、青空文庫のテキストファイルをePub3ファイルに変換するツールです。

【EPUBの作成方法】

青空文庫からダウンロードしたZIPファイルを使って、本アプリでEPUBファイルを簡単に作成できます。

手順：
1. アプリを起動し、「本文ファイルを読み込む」ボタンをタップします。
2. ダウンロードしたZIPファイルを選択します。
3. 「変換開始」ボタンをタップすると、EPUBファイルが作成されます。
4. 事前に「表紙画像を読み込む」で表紙画像を指定しておくと、EPUBファイルにその画像が表紙として使用されます。
